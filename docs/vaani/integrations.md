# Integrations

> Connect Vaani with WhatsApp and Cal.com

## WhatsApp

Connect your Vaani agents to WhatsApp to handle conversations over messaging in addition to voice.

<Steps>
  <Step title="Go to Integrations">
    Navigate to **Settings → Integrations → WhatsApp**.

    <Frame>
      <img src="https://mintcdn.com/vaaniai/qbCNNrD3Y2bpmOlt/images/screenshots/whatsapp-integration.png?fit=max&auto=format&n=qbCNNrD3Y2bpmOlt&q=85&s=603c9f8fe73d0632d6ce70e4d0569a52" alt="WhatsApp integration screen" width="2940" height="1596" data-path="images/screenshots/whatsapp-integration.png" />
    </Frame>
  </Step>

  <Step title="Connect Your WhatsApp Business Account">
    Follow the OAuth flow to link your WhatsApp Business account.
  </Step>

  <Step title="Assign to an Agent">
    Select which agent handles incoming WhatsApp messages.
  </Step>
</Steps>

***

## Cal.com

Integrate with Cal.com to allow your voice agents to book meetings directly during calls.

<Steps>
  <Step title="Go to Integrations">
    Navigate to **Settings → Integrations → Cal.com**.

    <Frame>
      <img src="https://mintcdn.com/vaaniai/qbCNNrD3Y2bpmOlt/images/screenshots/calcom-integration.png?fit=max&auto=format&n=qbCNNrD3Y2bpmOlt&q=85&s=61d9f35583c2a85611285ed72761c4e3" alt="Cal.com integration screen" width="2940" height="1596" data-path="images/screenshots/calcom-integration.png" />
    </Frame>
  </Step>

  <Step title="Add Your Cal.com API Key">
    Paste your Cal.com API key to authorize the integration.
  </Step>

  <Step title="Configure Booking Behavior">
    Set which calendar event type to use when the agent books a meeting.
  </Step>
</Steps>
